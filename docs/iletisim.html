İletişim ve hata bildirimi

Yanlış transfer, eksik oyuncu, sayfa hatası veya rehber önerisi için projenin GitHub bildirim alanını kullanabilirsiniz.

Nasıl ulaşabilirsiniz?

Proje herkese açık GitHub deposunda geliştirilmektedir. Bildirim oluşturmak için aşağıdaki bağlantıyı açın ve New issue seçeneğini kullanın.

GitHub sorun ve geri bildirim sayfasını aç →

Transfer hatası bildirirken

  • Oyuncunun sitede görünen adını yazın.
  • Sitede gösterilen kaynak ve hedef takımı belirtin.
  • FC26’da gördüğünüz mevcut takımı yazın.
  • Kullandığınız platformu ve varsa kadro güncelleme tarihini ekleyin.
  • Kişisel kayıt dosyanızı herkese açık alana yüklemeyin.

Teknik sorun bildirirken

Windows sürümü, uygulama sürümü ve hata mesajının kişisel bilgi içermeyen bölümünü paylaşın. Ekran görüntüsünde kullanıcı adınız, klasör yolunuz veya hesap bilginiz görünüyorsa önce kapatın.

Şifre, doğrulama kodu, GitHub token’ı, EA hesabı bilgisi veya ödeme bilgisi göndermeyin. Proje hiçbir zaman bu bilgileri istemez.

Yanıt ve düzeltme

Bildirimler uygunluk ve eldeki doğrulanabilir bilgiler çerçevesinde incelenir. Her gerçek dünya duyurusu otomatik olarak oyun içi değişiklik anlamına gelmediği için bazı talepler doğrulama bekleyebilir.
